## Role in the project

Each variable maps to a specific stage of the analysis.

**Primary input (CWT scalograms)**
`precio_bolsa_horario.csv` is the only input to the wavelet transform. Hourly spot prices are deflated to real pesos (`precio_bolsa_real.csv`) and segmented into non-overlapping daily windows, with or without a log transform (see Scalograms below). Each day's mean is removed before the CWT, so the scalograms carry only the intraday shape and become inputs to the VAE. The daily mean and standard deviation are kept as separate level variables.

**Regime validation (Interpretation and Validation)**
Once the VAE latent space is clustered into regimes, the following variables help identify what each regime represents:

- `aportes_energia_diario.csv` and `porcentaje_volumen_util_diario.csv` - direct proxies for hydrological stress. Low inflows and low reservoir levels correlate with El Nino episodes (2002-03, 2009-10, 2015-16, 2023-24) and historically precede price spikes.
- `generacion_real_horaria.csv` - reveals the generation mix shift. When hydro capacity drops, thermal plants increase output, which raises marginal costs and spot prices.
- `demanda_real_horaria.csv` and `demanda_sin_diaria.csv` - context for distinguishing price increases driven by supply constraints (regime-relevant) from those driven by demand growth (less relevant).
- `precio_bolsa_diario_ponderado.csv` - smoothed daily reference for quick time-series plots and correlation analysis.

**Limited coverage**
- `precio_escasez_superior.csv` covers only 2025-03 onward. Not usable for historical validation. Included for completeness.
- `max_precio_oferta_horario.csv` starts 2009-08. Usable for the second half of the dataset.

## Scalograms

Generated by `scripts/04_generate_scalograms.py --price {log,linear}` in `data/processed/scalograms/`. Both sets have 9,709 daily scalograms of 128 scales x 24 hours (Morlet `cmor1.5-1.0`, scales 1 to 128) and differ only in the log transform.

| Folder | `--price` | Series before the CWT | Level columns in metadata |
|---|---|---|---|
| `real_price_log/` | `log` | log real price, daily mean removed | `log_price_mean`, `log_price_std` |
| `real_price/` | `linear` | real price in COP/kWh, daily mean removed | `price_mean`, `price_std` |

Files in each folder:

| File | In git | Content |
|---|---|---|
| `scalograms.npy` | No (about 114 MB, regenerate with the script) | float32 array (9709, 128, 24), CWT magnitude scaled to [0, 1] with the global minimum and the set's 99.5th percentile, values above clipped |
| `scalogram_metadata.csv` | Yes | `window_id`, `start_datetime`, `end_datetime` and the two daily level columns of the set |
| `normalization_params.json` | Yes | Pre-CWT transform (`price_set`, `log_transform`, `daily_demean`), scaling (`global_min`, `upper_percentile`, `upper_value`, `clipped_fraction`), wavelet, scales and window |

## Notes

- Hourly files encode hours as columns (`Values_Hour01`..`Values_Hour24`), not rows, subsequet data processing follows in the project
- Raw monetary values are in Colombian pesos (COP) per kWh, nominal. Real prices (`precio_bolsa_real.csv`, `precio_bolsa_diario_real.csv`) are deflated with the chained DANE IPC (base January 2000 = 100)
- The API returns at most 30 days per request for hourly variables. `pydataxm` handles this internally
